# 개인정보처리방침

> 흔적 · Trace (이하 "서비스")는 사용자의 개인정보 보호를 매우 중요하게 생각합니다.
> 본 방침은 KISA 가이드와 개인정보 보호법을 준수합니다.

## 1. 수집하는 개인정보의 항목

| 구분 | 항목 | 수집 시점 |
|---|---|---|
| 필수 | 이메일, 이름(별명) | 회원가입 |
| 선택 | 교회명, 구역 코드, 알림 시간 | 온보딩 (모두 미입력 가능) |
| 자동 | 기기 식별자, 푸시 토큰, 앱 사용 통계 | 알림·통계 옵트인 시 |
| 결제 | 카드사, 카드 마지막 4자리 | Premium 구독 시 (전체 카드번호는 토스페이먼츠가 보관) |

## 2. 수집 목적

1. 본인 확인 및 회원 식별
2. 영성훈련 체크인 데이터 저장 및 본인 통계 제공
3. 구역 멤버 간 가시성 설정에 따른 카운트 공유
4. 알림 발송 (옵트인한 경우에만)
5. 결제 처리 및 부정결제 방지
6. 서비스 개선을 위한 익명 통계 (PII 마스킹)

## 3. 보유 및 이용 기간

- 회원 탈퇴 시 30일 유예 후 영구 삭제 (cascade)
- 결제 기록은 전자상거래법에 따라 5년 보관
- 부정 사용 의심 기록은 1년 보관

## 4. 제3자 제공·위탁

| 수탁자 | 항목 | 목적 |
|---|---|---|
| Supabase Inc. (DB·인증) | 가입 정보, 체크인 데이터 | 데이터 저장·인증 |
| 토스페이먼츠 | 카드 정보, 결제 금액 | 결제 처리 |
| Apple Push Notification | 푸시 토큰 | 알림 발송 (iOS) |
| Google FCM | 푸시 토큰 | 알림 발송 (Android) |
| OpenAI / Anthropic | 음성 녹음(짧은) | 성경 암송 STT, AI 묵상 (Premium 한정, 옵트인) |

## 5. 사용자의 권리

- 본인 데이터 열람·정정·삭제 요청 가능 (앱 내 [나 → 설정 → 프로필] 에서 본인 직접 처리)
- 탈퇴 시 30일 이내 복구 가능, 이후 영구 삭제
- 알림·통계·AI 묵상 등은 모두 옵트인이며 언제든 끌 수 있습니다

## 6. 율법주의 방지를 위한 데이터 정책

흔적 · Trace 는 신앙을 점수화하지 않습니다. 따라서:

- **노트·기도제목·암송 메모**는 어떤 경우에도 외부에 공유되지 않습니다 (구역장 포함).
- **랭킹·비교·평균**은 본인 데이터에 한해서만 표시합니다.
- 분석·에러 도구로 송출되는 모든 데이터는 PII 마스킹을 거칩니다.
